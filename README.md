# Penguins Magic
> 依赖社区接口的、高度开放的中立骚扰电话拦截工具。  
灵感来源于订阅代理工具，可自定义服务后端。

> 内部代号:[Anti You](https://projectsekai.fandom.com/wiki/ANTI_YOU)

## 从开发它的原因介绍它的功能
仓库维护者已无法忍受被某越速运的营销广告打爆手机且要求屏蔽也不予理会的情况。一个电话不接又会漏接政务电话。走投无路开发本项目。
---
这些电话要么是白号，要么是解封号码(交钱解封)，而一旦解封。系统自带的拦截就完全失效了。你还是拦不住他们的骚扰电话。
### 中立拦截，高度自定义。
你可以自定义自己的拦截策略，也可以添加其他人提供的拦截数据库订阅。这类似某些代理工具。每次拦截后，号码可以设置为自动进入本地拦截策略。这样即使后端的数据被不受信任的修改，也依然可以正确拦截号码。
---
但，有这些还完全拦不住这些电话，经常一次拦截了一两个号码，立刻会有其他电话打过来。接起来，“您是xxxx公司的x总吗？”。对的，他们不傻，会换号打。  
这种电话的规律我已完全摸清，一旦打不通电话(被拦截)，他们会以这个顺序呼叫你:  
`工作电话A-->工作电话B-->生活电话-->集团呼叫->本地号码`  
间隔不超过50s
### 连锁封禁
开启该功能时可以设置一个阈值，当某个号码命中拦截数据库或本地拦截策略被拦截后。1分30秒内拒接不在黑名单也不在通讯录内的陌生号码。连锁封禁拦截号码后，连锁封禁将延长30s。但最长不超过你设置的最大阈值。  
此时打开Penguins Magic可以手动临时解封、白名单、或列入本地拦截列表。(**小建议:这时可以去微信搜索一下这个号码，看到前面带广告的就可以列黑了。如果确实不认识可以暂时解封。看对方会不会再用同一个号码打回来**)
